运行程序只读取输入与真正生成的上游对象，不读取老师期望答案。基座不需要 LLM 服务即可运行；模型可用于扩展解析与 Skills 交互，但要保留客观验证。

## 已执行的验证与尚待验证

程序测试和Word视觉检查记录见 `docs/verification.md`。CI会在GitHub重跑。初始客户端侧 WorkBuddy 导入没有在学员机器验证，仓库明确记录 NOT_TESTED；学员可先用Python基座完成任务，再补实机证据。

相关代码可以独立运行，但不代表原需求全部 AC 已通过。譬如 M08-AC2 要求图片可见字段提取，目前未实现；M13 的第二模板适配也仍待贡献。

## 已开放任务的专项测试交接

11 项开放任务的 54 个专项用例见 `samples/acceptance/` 与 `docs/testing.md`，每项都有正常、需复核、异常和变更输入。包含无标签原文、真实合成图片、模板1.1、实际DOCX关系/内容错误、企业资料、确定性金额、复用许可与历史依赖图；输入、参考预期与哈希分别记录。

这些是测试材料和检查器，不是学员业务功能实现。`verify-kit` 的通过只说明材料完整；没有适配器会明确失败。CI新增检查器正反例和材料完整性回归，不能把它们计为11个新增模块已实现。使用新模板不代表已经合入 M13 模板1.1适配，也不代表 WorkBuddy 实机已验收。
