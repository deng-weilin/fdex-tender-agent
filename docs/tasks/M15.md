# [M15] 模拟提交标书，核对版本和提交回执

任务编号：M15-01。难度：进阶（先提交实施计划）。

开放计划：暂未开放，不要认领。维护者补齐练习原件和测试后才开放，不要求学员先自备这些材料。

## 你在帮谁解决什么问题

递交操作人需要知道准备交的是哪一版、文件齐不齐、是否在截止前，以及提交后有没有对应回执。你要做一个本地模拟核对流程，不执行任何真实投标上传。

|---|---|---|
| 规划说明 | [查看材料](../../samples/modules/M15/normal/input.json) | 不是已经可用的完整模拟平台。 |
| 开放前需补齐 | 尚未准备，不是现成练习包 | 独立全本模拟包、具名放行记录、要求附件、固定截止、成功/失败/无回执及不同项目回执；补一份模拟澄清请求。 |

现有说明或部分样例不等于完整测试材料已配齐；示意例子也不是现成原件。不要把基座的未确认/过期样例当成这个新模块的专项测试。

## 你具体要做什么

已有基础与这次新增：基座只有人员局部章节的模拟放行，不具备全本模拟递交能力。完整输入包尚待准备。

1. 核对准备包范围是给定的全本模拟范围，而不是仅有人员章节。
2. 检查文件清单、内容指纹、具名放行和截止时间，任何一项不符都不能标提交成功。
3. 对照模拟平台回执的项目、标包、提交版本和结果；没有回执不能猜成功。
4. 记录失败与重试，同一提交包重试不能重复登记一次成功。
5. 把整个过程清楚标为教学模拟，不自动访问交易平台。
6. 模拟澄清请求关联原提交版本、答复期限与责任人，答复未确认不能标已发送。

## 做完后交什么

- submission_record.json、提交核对清单和模拟回执对账结果。
- 固定版本模拟包的记录、失败/重试历史，以及限定的澄清跟踪草稿。
