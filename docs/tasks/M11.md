# [M11] 填写商务表，列出不能承诺和待签署的内容

任务编号：M11-01。难度：常规。

开放计划：暂未开放，不要认领。维护者补齐练习原件和测试后才开放，不要求学员先自备这些材料。

## 你在帮谁解决什么问题

商务同事要填写资格表和商务响应表。不是每条条件都能直接答应，也不是文件填完就等于已经签字盖章。你要帮他填入有依据的信息，列出差异、缺资料和待签署事项。

现有说明或部分样例不等于完整测试材料已配齐；示意例子也不是现成原件。不要把基座的未确认/过期样例当成这个新模块的专项测试。

## 你具体要做什么

已有基础与这次新增：基座没有独立商务响应模块。本任务规划一张资格材料表和一张商务偏离表，不做全套商务文件。

1. 按指定表头填写有来源的企业信息和资格材料，缺什么就写待取得。
2. 逐条核对商务要求与企业提供的立场，不能默认所有条件完全响应。
3. 把不一致的条件列入偏离表，注明原要求、企业立场和需要谁确认。
4. 授权、无不良记录等声明没有确认时不能当成已经作出的正式声明。
5. 签字、盖章仅记录位置和待办，不能制造签名或印章。
6. 检查企业名称、项目编号和期限与其他资料一致。

## 做完后交什么

- commercial_response.json、资格表与商务偏离表草稿。
- 资料缺口、待确认声明及待签署清单。

本次不要求或不能做的事：

- 不自行决定付款、担保、责任等商务立场。
- 不真实签章、不转账、不声称已取得未提供的资格。

由商务负责人确认，确认内容再交 M13；待确认内容保留提示。
