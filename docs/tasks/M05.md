# [M05] 登记是否参与投标的决定和条件

任务编号：M05-01。难度：入门。

开放计划：暂未开放，不要认领。维护者补齐练习原件和测试后才开放，不要求学员先自备这些材料。

## 你在帮谁解决什么问题

业务负责人可能已经线下决定参与一个项目，也可能还在等资料。你要把“建议参与”和“负责人已经决定参与”分开记录，避免AI写一句建议就被当成正式批准。

## 你具体要做什么

已有基础与这次新增：基座样例已有“线下决定参与”的输入标记，但没有完整的独立决策模块。本任务规划决定登记与资料不足时的条件性建议。

1. 读取招标要求和已提供的企业资料，说明目前哪些依据齐全、哪些还缺。
2. 分别记录程序建议与负责人提供的最终决定，不能互相代替。
3. 负责人已在线下决定参与时，登记决定人、时间、范围和条件，不要求重复创造一份AI批准。
4. 没有确认时保持待确认；只有招标文件不能写公司全部满足。
5. 参与决定不替代人员选用、报价或递交审批；发现材料矛盾仍提示处理。
6. 关键需求变了，列出需要重新确认参与条件的事项。

## 做完后交什么

- bid_decision.json 和中文决定摘要。
- 建议、已有决定、决定依据、负责人、时间及仍未解决问题的独立记录。

- 不自动决定参加投标，不编造确认人或投入资源。
