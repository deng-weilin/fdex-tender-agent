# [M09] 检查公司资料是否符合要求，并记录选用确认

任务编号：M09-01。难度：常规。

开放计划：可申请认领；实际状态、负责人和认领结果以此Issue的标签及机器人回执为准。

## 你在帮谁解决什么问题

项目要求企业具有某种资格，资料管理员给来几份文件。负责人需要看到哪些文件可以作为候选、哪些过期或信息不全，再确认这次使用哪一份。你要补公司资料匹配，并把候选与正式选用分开。

## 我们提供哪些材料

| 材料 | 在哪里 | 用来做什么 |
|---|---|---|
| 合成公司资格原件 | [查看材料](../../samples/acceptance/shared/company) | 正常、有效期未知、过期和更新版文字原件。 |
| 本任务测试入口 | [查看材料](../../samples/acceptance/M09/normal/input.json) | 包含资格要求、判断日期和单独的公司资料选用确认；还有未知资产的异常。 |

以上专项原件已提供，取得和查看这些材料不需要真实客户资料或服务密钥。故意缺失/损坏的文件是异常测试，按用例报错或转核对，不向老师补要原件。测试包来自 [精确测试版本](https://github.com/iurp/fdex-tender-agent/blob/19433e19434354e113f6569b4a102684abac317c/samples/acceptance/README.md)；是否合入main以 [PR #23](https://github.com/iurp/fdex-tender-agent/pull/23) 为准。

## 你具体要做什么

已有基础与这次新增：基座已有人员证书候选和输入确认。本次扩展一类公司资格资料；不要求重新做人员选用页面。

1. 把公司资料里的资格、主体和有效期与本项目要求对照，说明符合、不足、过期或需核对的原因。
2. 没有有效期依据时标待核对；过期不能标成已经满足。
3. 匹配到候选后，仍要检查本次资料选用确认：确认对象、版本、人、时间和范围都要明确。
4. 没有确认就不能交给文档制作作为已选资料；选了不存在的材料编号时阻断。
5. 资料换成新版本后，原确认不能自动继承；保留旧资料及旧选用记录。
6. 公司资料确认不等于人员确认，也不等于已批准报价或正式投标。

## 做完后交什么

- asset_match.json、确认记录和中文候选/缺口清单。
- 每个匹配结论的要求与原件出处，确认范围及变化后的处理结果。

交付效果示例：

> 公司资格资料符合要求且在有效期内，可以作为候选；没有本次负责人确认时仍未正式选用。换成资料2.0后，原来针对1.0的确认变为失效，需要重新确认。

本次不要求或不能做的事：

- 不自动选用资料，不证明企业实际履约能力。
- 本次不要求做完整公司资料库或所有业绩类型。

把经确认的本次选用资料交给 M13；未确认部分只交候选和待办。

## 怎么判断完成

先用本任务现成的用例验证，不能只演示一次正常结果：

| 用例 | 你要证明什么 |
|---|---|
| [正常](../../samples/acceptance/M09/normal/case.json) | 企业资格有独立对象确认 |
| [待核对](../../samples/acceptance/M09/review/case.json) | 有效期未知且没有确认 |
| [异常](../../samples/acceptance/M09/abnormal/case.json) | 过期企业资料不能满足资格 |
| [变更](../../samples/acceptance/M09/change/case.json) | 换材料后旧确认摘要失效 |
| [不存在的资料](../../samples/acceptance/M09/unknown-id/case.json) | 不存在的资产确认不能选用 |

交出这些用例的实际运行报告、原始输出和本次新增测试。

还要保留一次有关已生成文件的联调记录，说明你实际读了什么。如果先用独立教学输入验证新增部分，明确这个范围和接入方式，不能冒充整条流程已经接通。

只有材料完整不等于功能完成；固定公开样例通过也不能替代独立代码审查，复审还会改变合法输入检查是否硬编码。

## 技术附录

这里是实现时查阅的约定，不需要先背术语才能理解前面的任务。

| 术语 | 这道任务里的意思 |
|---|---|
| 候选 | 程序认为可能符合要求的材料，还不代表负责人已选用。 |
| 确认摘要 | 绑定具体内容的指纹，内容变了就不能沿用旧确认。 |

机器输出仍使用已有JSON约定，`bid-training.workflow.v1`只是程序统一读取结果的格式名称，不是额外业务目标。字段细节看 [接口说明](../../docs/interfaces.md)。
