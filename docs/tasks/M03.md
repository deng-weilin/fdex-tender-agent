# [M03] 整理招投标文件：找重复、辨版本、查缺件

任务编号：M03-01。难度：入门。

开放计划：可申请认领；实际状态、负责人和认领结果以此Issue的标签及机器人回执为准。

## 你在帮谁解决什么问题

招投标负责人收到招标原件、别人转发的副本、后来收到的修改文件、附件和填写模板。他不知道哪些重复、内容有没有改、附件有没有收齐。你要开发一个文件整理功能，让他能看清楚这批文件，同时保留原件。

## 我们提供哪些材料

| 材料 | 在哪里 | 用来做什么 |
|---|---|---|
| 原件、转发副本和修改文件 | [查看材料](../../samples/acceptance/shared/files) | original/tender.md要求至少3名人员；copy/tender-copy.md与它内容相同；revised/tender.md同名但要求至少4名；还提供附件A。 |
| 填写模板 | [查看材料](../../templates/personnel-v1.docx) | 原文要求提供的人员表模板。 |
| 本任务测试入口 | [查看材料](../../samples/acceptance/M03/normal/input.json) | 列出5份实际文件及应检查的附件；其他用例故意缺件或混入不同项目。 |

以上专项原件已提供，取得和查看这些材料不需要真实客户资料或服务密钥。故意缺失/损坏的文件是异常测试，按用例报错或转核对，不向老师补要原件。测试包来自 [精确测试版本](https://github.com/iurp/fdex-tender-agent/blob/19433e19434354e113f6569b4a102684abac317c/samples/acceptance/README.md)；是否合入main以 [PR #23](https://github.com/iurp/fdex-tender-agent/pull/23) 为准。

## 你具体要做什么

已有基础与这次新增：基座已经能登记文件位置并计算内容指纹。本次新增重复识别、同名版本差异和缺件提示，不是重新开发整套文件上传系统。

1. 列出收到的文件，记录名称、位置、类型、提供的版本、所属项目和标包以及能否读取。
2. 找出内容完全相同的文件，标为重复；保留收到副本的记录，不删除原件。
3. 找出名字相同但内容不同的文件，提示存在版本差异，两份都保留。
4. 对照要求的附件清单，列出还没收到的附件；不能把缺件当成已经收齐。
5. 没有明确说明新文件替代旧文件时，提示负责人确认使用哪一版，不能仅按上传时间决定。
6. 发现其他项目或标包的文件时提示归属不符，不混入本项目。

## 做完后交什么

- source_manifest.json：程序可读取的文件清单，包括身份编号、内容指纹、位置、类型、版次和读取状态。
- 一份中文整理结果：重复文件、同名内容差异、缺件以及需要负责人确认的事项。

交付效果示例：

> 已收到5份文件。原始招标文件与转发副本内容相同；修改文件把人员要求从3名改成4名，原件和修改文件均保留。正常样例附件齐全；缺件样例提示缺少附件A。未取得覆盖依据时仍需确认使用版本。

本次不要求或不能做的事：

- 本任务不生成新Word、不制作标书，也不要求做网页。
- 允许直接从文件列表开始，不要求等待公告采集或先生成其他模块的JSON。
- 报名、保证金等完整项目流程不属于本次新增范围。

文件清单让 M04 知道该读哪些原文，让 M08 知道材料原件在哪里。

## 怎么判断完成

先用本任务现成的用例验证，不能只演示一次正常结果：

| 用例 | 你要证明什么 |
|---|---|
| [正常](../../samples/acceptance/M03/normal/case.json) | 重复内容与同名不同内容均保留 |
| [待核对](../../samples/acceptance/M03/review/case.json) | 有修订但无覆盖关系，不能判最终版 |
| [异常](../../samples/acceptance/M03/abnormal/case.json) | 原文引用的附件未提供 |
| [变更](../../samples/acceptance/M03/change/case.json) | 其他项目与标包不得混入 |

交出这些用例的实际运行报告、原始输出和本次新增测试。

本任务直接从实际文件、图片或给定数值开始，用它们运行即可，不要求先等其他模块生成结果。与后续程序交接时，说明输出怎样被读取。

只有材料完整不等于功能完成；固定公开样例通过也不能替代独立代码审查，复审还会改变合法输入检查是否硬编码。

## 技术附录

这里是实现时查阅的约定，不需要先背术语才能理解前面的任务。

| 术语 | 这道任务里的意思 |
|---|---|
| 哈希或内容指纹 | 根据文件字节计算的识别值，用来发现内容完全相同或发生变化；不是文件名。 |
