# [M07] 把招标要求分成有负责人和期限的任务

任务编号：M07-01。难度：入门。

开放计划：可申请认领；实际状态、负责人和认领结果以此Issue的标签及机器人回执为准。

## 你在帮谁解决什么问题

负责人知道招标要求，却还不清楚谁准备哪份资料、填哪一处表格、何时完成。你要把逐条要求变成能执行的制作任务，而不是只列一堆要求。

## 我们提供哪些材料

| 材料 | 在哪里 | 用来做什么 |
|---|---|---|
| 本任务测试入口 | [查看材料](../../samples/acceptance/M07/normal/input.json) | 直接给出人员/格式/报价三类要求、角色配置、任务期限和业务截止；还有缺值、超期、新列样本。 |
| 实际基座制作记录 | [查看材料](../../samples/e2e/core-normal) | 运行后可查看response_matrix.json和task_plan.json，了解它们怎样交接。 |

以上专项原件已提供，取得和查看这些材料不需要真实客户资料或服务密钥。故意缺失/损坏的文件是异常测试，按用例报错或转核对，不向老师补要原件。测试包来自 [精确测试版本](https://github.com/iurp/fdex-tender-agent/blob/19433e19434354e113f6569b4a102684abac317c/samples/acceptance/README.md)；是否合入main以 [PR #23](https://github.com/iurp/fdex-tender-agent/pull/23) 为准。

## 你具体要做什么

已有基础与这次新增：基座已有人员章节的要求与位置对应，但责任角色固定、任务期限为空。本次让它读取分工配置和明确期限。

1. 为本次包含的要求登记放到哪个章节、表格或字段，需要什么材料。
2. 从输入配置读取责任角色和期限，不把所有任务都交给固定角色。
3. 任务期限不能晚于对应业务截止；缺负责人或期限时说明缺什么，不默认填今天。
4. 本次不做的报价等内容明确排除，分别统计本次范围与全本范围。
5. 模板多了一列而没有对应填写规则时，提示需要适配，不能把数据静默填错位置。
6. 保留要求到任务的对应编号，让资料检查和文档制作能读取同一份计划。

## 做完后交什么

- response_matrix.json、task_plan.json 和中文任务清单。
- 每项的要求出处、输出位置、材料、责任角色、期限以及缺口。

交付效果示例：

> 人员资料由资料管理员负责，10月30日18点前准备；表格由文档负责人负责，10月31日18点前填写。业务截止是11月1日10点。报价不在本次人员章节范围，单列为未制作。

本次不要求或不能做的事：

- 不擅自指定真实同事或替负责人确认分工。
- 不做完整项目管理页面，也不要求完成未纳入范围的技术/报价章节。

M09读计划查材料，M13读计划把内容放进正确位置。

## 怎么判断完成

先用本任务现成的用例验证，不能只演示一次正常结果：

| 用例 | 你要证明什么 |
|---|---|
| [正常](../../samples/acceptance/M07/normal/case.json) | 配置责任与期限并分别统计范围 |
| [待核对](../../samples/acceptance/M07/review/case.json) | 缺责任或期限不能填当天 |
| [异常](../../samples/acceptance/M07/abnormal/case.json) | 任务期限晚于业务截止 |
| [变更](../../samples/acceptance/M07/change/case.json) | 新列在未提供映射时提示适配 |

交出这些用例的实际运行报告、原始输出和本次新增测试。

还要保留一次有关已生成文件的联调记录，说明你实际读了什么。如果先用独立教学输入验证新增部分，明确这个范围和接入方式，不能冒充整条流程已经接通。

只有材料完整不等于功能完成；固定公开样例通过也不能替代独立代码审查，复审还会改变合法输入检查是否硬编码。

## 技术附录

这里是实现时查阅的约定，不需要先背术语才能理解前面的任务。

| 术语 | 这道任务里的意思 |
|---|---|
| 响应矩阵 | 要求与制作位置、材料、负责人之间的对应表。 |
| due_time | 某项制作任务需要完成的时间，不一定等于投标截止。 |

机器输出仍使用已有JSON约定，`bid-training.workflow.v1`只是程序统一读取结果的格式名称，不是额外业务目标。字段细节看 [接口说明](../../docs/interfaces.md)。
