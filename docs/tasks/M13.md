# [M13] 把确认的人员资料填进新版 Word 模板

任务编号：M13-01。难度：常规。

开放计划：可申请认领；实际状态、负责人和认领结果以此Issue的标签及机器人回执为准。

## 你在帮谁解决什么问题

招投标制作人员收到新版人员表，比旧版多了“资格类型”一列。你要让程序把已经确认的3名人员和对应证书填到新版表格，并真正生成可编辑Word；换人后不能留下旧资料。

## 我们提供哪些材料

| 材料 | 在哪里 | 用来做什么 |
|---|---|---|
| 新版可编辑模板及填写规则 | [查看材料](../../samples/acceptance/shared/word) | personnel-v1.1.docx新增资格列；template-manifest-v1.1.json说明六列和对应字段。 |
| 本任务测试入口 | [查看材料](../../samples/acceptance/M13/normal/input.json) | 提供已确认人员、证书图片、项目字段、具名合成确认和实际生成的前序JSON；包含换人、未确认、模板错版、跨标包和缺图。 |

以上专项原件已提供，取得和查看这些材料不需要真实客户资料或服务密钥。故意缺失/损坏的文件是异常测试，按用例报错或转核对，不向老师补要原件。测试包来自 [精确测试版本](https://github.com/iurp/fdex-tender-agent/blob/19433e19434354e113f6569b4a102684abac317c/samples/acceptance/README.md)；是否合入main以 [PR #23](https://github.com/iurp/fdex-tender-agent/pull/23) 为准。

## 你具体要做什么

已有基础与这次新增：基座能制作模板1.0的人员章节。本次只适配模板1.1和新增资格列，不承诺任意模板都能使用。

1. 读取指定模板和填写规则，确认文件内容与登记的模板版本一致。
2. 将确认的3名人员的角色、姓名、证号、有效期、原件位置和资格类型填进正确的六列。
3. 插入3张对应证书，检查图片与人员及证号一致，不只填写图片路径。
4. 换一名人员时更新姓名、证号、资格列和图片，不能保留旧姓名、编号或图片字节。
5. 没有确认、缺图片、模板内容不符或属于另一标包时，说明原因并阻断相关装配。
6. 每轮写入新目录；用Word/WPS或渲染预览检查每页中文、列宽、图片和分页。

## 做完后交什么

- 实际可编辑的人员章节DOCX，以及assembly_result.json。
- 填写位置与原资料对应记录、生成文件内容指纹、未制作范围和逐页视觉检查证据。

交付效果示例：

> 新版表最后一列“资格类型”实际填入对应资格。将人员丙换成人员丁后，表格和附件同步变成丁的资料，文档里不能残留丙的姓名、证号或图片。

本次不要求或不能做的事：

- 只做人员资质局部章节，不做整本标书或任意Word模板。
- 不把未确认人员作为已选人员装配；截图或Markdown不能替代实际Word文件。

把实际Word和填写对应记录交给 M14 独立检查。
