# 任务测试适配器

此目录暂不提供 M03 等任务的完成实现。每位开发者新增自己认领任务的适配器，例如 `adapters/m12.py`，读取测试 input.json、调用自己的功能并生成实际文件和 result.json。

约定和最小代码骨架见 [测试指南](../docs/testing.md)。检查器负责读 expected.json，业务程序和适配器不得读取参考预期。需要自测时，由学员在自己的无秘密本地环境执行适配器；维护者通过隔离 CI 验证 PR，不在带账号/SSH/API secrets 的进程里运行陌生贡献者代码。

测试适配层不是生产接口变更，也不是可以替代模块实现的固定答案生成器。
